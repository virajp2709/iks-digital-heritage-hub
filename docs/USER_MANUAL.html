2. How to Access & Download the Codebase

Anyone—including college IT staff, faculty mentors, or student researchers—can access the full codebase via GitHub in two primary ways:

Method A: Cloning via Git (Recommended for Developers & Admins)

Clone the complete repository with all history, assets, and project data to your local machine using terminal or PowerShell:

# 1. Open Terminal, Command Prompt, or PowerShell git clone https://github.com/virajp2709/iks-digital-heritage-hub.git # 2. Enter project directory cd iks-digital-heritage-hub # 3. Open in VS Code code .
Method B: Direct ZIP Download (For Offline Review & Presentation)
  1. Visit the GitHub link in any web browser: https://github.com/virajp2709/iks-digital-heritage-hub
  2. Click the green "Code" button located at the top right of the file list.
  3. Select "Download ZIP" from the dropdown menu.
  4. Extract the downloaded archive (iks-digital-heritage-hub-main.zip) to any folder.
  5. Double-click index.html to launch the main hub or websites.html to launch the student websites portal in any modern web browser.
3. Connecting with College GitHub or Any Organization Account

To link or transfer the project to the official VPKBIET college GitHub organization (e.g., github.com/vpkbiet) or another department account, follow either of the following approaches:

Approach 1: Forking the Repository (Preserves Upstream Link)
  1. Log in to the destination GitHub account (e.g. college organization account).
  2. Navigate to https://github.com/virajp2709/iks-digital-heritage-hub.
  3. Click the "Fork" button at the top right of the repository page.
  4. Under "Owner", choose your college organization or personal handle, name the repository, and click "Create fork".
  5. The repository is now duplicated under your organization while retaining the ability to sync future updates with one click via "Sync fork".
Approach 2: Pushing to a Fresh Institutional Remote

If the college prefers an independent repository without a fork badge:

# 1. Create a new empty repository on the College GitHub (e.g., vpkbiet-iks-hub) # 2. On your local machine inside the cloned folder, add the college remote git remote add college https://github.com/vpkbiet/vpkbiet-iks-hub.git # 3. Push all code and branches directly to the college repository git push -u college main
4. Step-by-Step: Adding GitHub Token (PAT) for Automated Sync

Since August 2021, GitHub requires a Personal Access Token (PAT) instead of an account password for secure command-line Git operations (git push, git fetch). Follow these exact steps to generate and authenticate using a token:

Step 1: Generate a Personal Access Token on GitHub
  1. Log in to your GitHub account and click your Profile Icon in the top-right corner.
  2. Click Settings from the dropdown menu.
  3. In the left sidebar, scroll down to the bottom and click "Developer settings".
  4. Under "Personal access tokens", click "Tokens (classic)".
  5. Click the button "Generate new token" → "Generate new token (classic)".
  6. Configure the token parameters:
    • Note: Enter a recognizable name, e.g., VPKBIET-IKS-Hub-Sync-Token
    • Expiration: Choose 90 days or No expiration (for institutional automated pipelines).
    • Scopes (Permissions): Check the following essential checkboxes:
      • [X] repo (Full control of private repositories & commit access)
      • [X] workflow (Allows triggering GitHub Actions & deployments)
  7. Scroll to the bottom and click the green "Generate token" button.
  8. CRITICAL: Copy the displayed token immediately (format begins with ghp_...). GitHub will never show it to you again. Store it securely in a password manager.
Step 2: Configure the Token on Your Computer

Configure Git to use your token for password-less, secure pushes:

# Option A: Embed token directly in Git remote URL (Quickest & permanent) git remote set-url origin https://<YOUR_GITHUB_TOKEN>@github.com/<USERNAME>/<REPO>.git # Example for this repository: git remote set-url origin https://ghp_YourSecretTokenHere@github.com/virajp2709/iks-digital-heritage-hub.git # Option B: Use Git Credential Manager (Prompts once, then remembers securely) git config --global credential.helper manager
Step 3: Test Synchronization by Pushing Changes
# Stage modified files git add . # Commit with a clear descriptive message git commit -m "Update student project catalog and website showcase" # Push live to GitHub main branch git push origin main
Pro Tip: When prompted in terminal for your username and password, enter your GitHub username and paste your Personal Access Token (ghp_...) into the password field.
5. Enabling Free GitHub Pages & Linking to College Website (vpkbiet.org)

The platform is designed to be hosted 100% free with 99.99% uptime via GitHub Pages, with automatic SSL (HTTPS) encryption.

Step 1: Turn On GitHub Pages
  1. Go to your repository on GitHub → Click Settings tab → Click Pages in the left sidebar.
  2. Under "Build and deployment" → Source: Select Deploy from a branch.
  3. Under Branch: Select main and folder / (root) → Click Save.
  4. Within 60 seconds, GitHub Pages compiles and publishes the portal at:
    https://<organization>.github.io/<repository-name>/
Step 2: Linking from the Official College Website (vpkbiet.org)

The college IT web administrator can integrate this portal on vpkbiet.org using any of the three standard integration patterns:

  1. Navigation Bar / Menu Link (Recommended): Add an item named "IKS Heritage Hub" or "Indian Knowledge Systems" to the college website header/footer:
    <a href="https://virajp2709.github.io/iks-digital-heritage-hub/" target="_blank" rel="noopener noreferrer"> 🏛️ IKS Digital Heritage Hub </a>
  2. Custom Subdomain (e.g. iks.vpkbiet.org): In GitHub Pages settings, under "Custom domain", enter iks.vpkbiet.org. In college domain DNS manager, add a CNAME record pointing iks to virajp2709.github.io. Check "Enforce HTTPS".
  3. Embedded iFrame on College Page: Embed the entire hub seamlessly inside an existing college web template:
    <iframe src="https://virajp2709.github.io/iks-digital-heritage-hub/" style="width:100%; height:900px; border:none;" title="VPKBIET IKS Hub"></iframe>
